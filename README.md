# תחבורה ציבורית מותאמת אישית
## חבילת הפרויקט

**סטטוס:** אפיון, ואב־טיפוס ווב עם מנוע מסלולים ולוחות זמנים אמיתיים של משרד התחבורה (`prototype-web/`). עדיין אין אפליקציית Android. זמן אמת מגיע באופן זמני מ־Open Bus Stride.  
**פלטפורמה ראשונה:** Android.  
**שפת המוצר הראשונית:** עברית, עם תמיכה מלאה ב־RTL.  
**עיקרון מעקב:** איסוף נתוני נסיעה רק כשהאפליקציה פתוחה.

### חזון
אפליקציית ניווט לתחבורה ציבורית בסגנון Waze, שמתחילה מנתוני תחבורה זמינים ומשפרת בהדרגה את אומדני הזמנים עבור כל משתמש, על סמך הנסיעות שהוא ביצע בפועל ועל סמך נתונים מצרפיים מאושרים של משתמשים אחרים.

### קבצים בחבילה
- `docs/PRODUCT_SPEC.md` — האפיון הראשי, גרסה 2.0. עותק Word: `docs/PRODUCT_SPEC_v2.0.docx`. גרסה 1.0 שמורה ב־`docs/archive/`.
- `docs/REQUIREMENTS.md` — דרישות פונקציונליות ולא־פונקציונליות וקריטריוני קבלה.
- `docs/TECHNICAL_ARCHITECTURE.md` — ארכיטקטורה מוצעת.
- `docs/DATA_MODEL.md` — מודל נתונים ראשוני.
- `planning/ROADMAP.md` — שלבי פיתוח ותוכנית עתידית.
- `planning/DECISIONS.md` — החלטות מוצר ידועות והנחות פתוחות.
- `planning/CHECKLIST.md` — מה צריך כדי להתקדם ומה חסר.
- `prompts/CLAUDE_CODE.md` — הנחיות עבודה לכלי פיתוח מבוססי AI.
- `AGENTS.md` — כללי עבודה כלליים לסוכני קוד.
- `docs/RESPONSE_STYLE.md` — הנחיות עיצוב תשובות.
- `docs/DATA_FORMAT.md` — איך נבנים קובצי הנתונים מה־GTFS ומה הפורמט שלהם.
- `docs/REALTIME.md` — תכנון החיבור לזמן אמת (SIRI-SM של משרד התחבורה).
- `scripts/`, `data/`, `prototype-web/`, `tests/` — אב־הטיפוס, הנתונים והבדיקות.

### לפני פיתוח
לוחות הזמנים מגיעים מה־GTFS הפתוח של משרד התחבורה. עדיין יש לאשר את מקור זמן האמת (בקשת גישה ל־SIRI-SM), מדיניות פרטיות, תשתית שרת ועלויות. באב־הטיפוס יש זמן אמת זמני מ־Open Bus Stride (`docs/REALTIME.md`).

### איך להשתמש
1. קראו תחילה את `docs/PRODUCT_SPEC.md`.
2. עברו על `docs/REQUIREMENTS.md` ואשרו את היקף גרסת MVP.
3. קבעו ספקי נתונים וטכנולוגיות לפני יצירת שלד Android.
4. פתחו משימות פיתוח קטנות לפי סדר העדיפויות ב־`planning/ROADMAP.md`.
