# האתר

אתר סטטי לתכנון נסיעות בתחבורה ציבורית בגוש דן (החלטות 3, 14, 17–19 ב־`planning/DECISIONS.md`). אין לו שרת משלו: החישוב רץ בדפדפן, והנתונים נבנים מחדש כל בוקר.

## מבנה
- **`site/`:** קוד המקור של הדף.
  - `index.html`, `css/app.css`.
  - `js/app.js`: הממשק. הוא פונה למנוע רק דרך `planTrip`.
  - `js/engine.js`: מנוע המסלולים (RAPTOR) ופענוח הנתונים.
  - `js/realtime.js`: זמן אמת מ־Open Bus Stride, ושעון ישראל.
  - `js/geocode.js`: חיפוש כתובות דרך Photon.
  - `js/map.js`: המפה (Leaflet).
- **`public/`:** האתר הבנוי. התיקייה לא נשמרת ב־git.
  - `public/data/`: קובץ לכל יום (`gushdan_<date>.json`), וקובץ `manifest.json` עם רשימת הימים ומועד העדכון.
- **`scripts/build_site.sh`:** בונה נתונים להיום ולשני הימים הבאים, ומעתיק את קבצי הדף. כדי להעתיק רק את קבצי הדף, בלי לבנות נתונים מחדש: `--skip-data`.

## הרצה מקומית
```bash
scripts/build_site.sh
```
```bash
python3 -m http.server 8766 --directory public
```
ואז לפתוח בדפדפן את הכתובת http://localhost:8766.

## בדיקות
```bash
node tests/engine_test.mjs
```
הבדיקה רצה על הנתונים שב־`public/data`, ובוחרת את היום עם הכי הרבה נסיעות. הבדיקה הישנה, `tests/routing_test.js`, בודקת את אב־הטיפוס.

## הממשק של המנוע
`engine.planTrip(query)` מחזיר תוצאה בפורמט שמתואר בראש `site/js/engine.js`: מסלולים, ובכל מסלול מקטעים. לכל מקטע יש זמנים, מקומות עם קואורדינטות, קו, תחנות, מקור הזמן וזמן אמת. הפורמט דומה למה שמחזירים מנועים כמו OpenTripPlanner.

כדי לעבור בעתיד למנוע חינמי שרץ על שרת (`docs/ROUTING_ENGINE.md`), כותבים מימוש אחר של `planTrip` שפונה לשרת ומתרגם את התשובה לאותו פורמט. `app.js` לא משתנה.

## פרסום
`.github/workflows/deploy.yml` רץ כל יום ב־04:30 בישראל, בכל דחיפה ל־main, וגם כשמפעילים אותו ידנית. הוא בונה, מריץ בדיקות ומפרסם ל־GitHub Pages.

**מה צריך פעם אחת:**
1. מאגר ציבורי ב־GitHub.
2. בהגדרות המאגר: Settings, ואז Pages, ואז Source = GitHub Actions.

**סיכון:** אם השרת של משרד התחבורה יחסום את השרתים של GitHub, הבנייה תיכשל, והאתר יישאר עם הנתונים של היום הקודם. במקרה כזה הפתרון הוא לבנות את הנתונים במחשב המקומי (`scripts/daily_update.sh`) ולדחוף אותם.

## פרטיות
- "המיקום שלי" נשאר בדפדפן. הוא לא נשמר ולא נכתב לכתובת הדף.
- חיפושים אחרונים והעדפות נשמרים רק בדפדפן (localStorage).
- המוצא והיעד נכתבים בחלק של הכתובת שאחרי #, שהדפדפן לא שולח לשרת. זה נועד לשיתוף.
- הטקסט שמוקלד בחיפוש נשלח ל־Photon כדי למצוא כתובות.
