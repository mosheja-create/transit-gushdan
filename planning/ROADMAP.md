# מפת דרכים

**עדכון 16.10.2026:** השלבים עודכנו לפי אפיון 2.0 (פרק 15). Session המעקב, ההיסטוריה והתיקון הידני עברו לשלב 1. נוספו המשימות שכבר בוצעו באב־הטיפוס.

## שלב 0 — אימות היתכנות (Proof of Concept)
- [x] לבחור ספק נתוני תחבורה ציבורית בישראל: GTFS של משרד התחבורה; זמן אמת מ־SIRI-SM (בקשת גישה טרם הוגשה).
- [ ] לבדוק תנאי שימוש, כיסוי, עדכניות ועלויות.
- [ ] לבחור ספק מפות ונתוני הליכה.
- [ ] להגדיר מדיניות פרטיות ואיסוף מיקום.
- [ ] להגדיר מדד דיוק בסיסי ומקרי בדיקה.
- [x] אב־טיפוס ווב שמחשב מסע מלא (הליכה, המתנה, נסיעה, החלפה) על לוחות זמנים אמיתיים של תל אביב יפו ורכבת ישראל, עם עדכון יומי אוטומטי.
- [x] זמן אמת זמני מ־Open Bus Stride, עם הערכת איחור לכל נסיעה.
- [ ] להגיש בקשת גישה ל־SIRI-SM של משרד התחבורה.
- [ ] להשוות מנועי מסלולים קיימים ולבחור אחד (החלטה 14).
- [ ] להקליט Session נסיעה יזום, למדוד הליכה ועצירה ולהציג ציר זמן בסיסי.
- [ ] לבדוק צריכת סוללה ואיכות GPS.

**תנאי מעבר:** ניתן לקבל ולפרש נתוני תחנות, קווים ולוחות זמנים ברישיון מתאים.

- [ ] פירוט הליכה, המתנה, נסיעה והחלפות.
- [ ] טיפול בשגיאות רשת ובנתונים חסרים.
- [ ] בדיקות בסיסיות לחישובי זמן.
- [ ] העדפות בסיסיות: זמן, הליכה, מספר החלפות ואמצעי תחבורה.
- [ ] Session מעקב יזום כשהאפליקציה פתוחה (הועבר משלב 2).
- [ ] סיכום נסיעה והיסטוריה בסיסית (הועבר משלב 2).
- [ ] תיקון ידני של אירועים (הועבר משלב 2).
- [ ] מסך פרטיות והרשאות, מחיקת נתונים, ניטור תקלות.

**תנאי מעבר:** משתמש יכול לחפש מסלול, להבין את כל שלביו, ולתעד נסיעה.
