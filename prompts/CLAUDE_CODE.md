## פרומפט פתיחה מוצע
אתה מוביל פיתוח Android מנוסה. אנחנו בונים אפליקציה בשם "תחבורה ציבורית מותאמת אישית". קרא את כל מסמכי הפרויקט לפני כתיבת קוד. אל תבנה עדיין את כל המוצר בבת אחת. תחילה:
1. סכם את הדרישות וההחלטות שכבר התקבלו.
2. הצג שאלות פתוחות שחוסמות פיתוח, במיוחד ספק נתוני התחבורה.
3. הצע שלד Android קטן, מודולרי ונבדק.
4. הפרד בין נתוני דוגמה לבין נתונים אמיתיים.
5. אל תמציא זמני תחבורה או API שאינם קיימים.
6. הצג תוכנית עבודה מדורגת והמתן לאישור לפני יצירת רכיבים גדולים.

## כללי פיתוח
- כל שינוי משמעותי חייב לכלול בדיקות מתאימות.
- אל תכניס מפתחות API לקוד.
- אל תפעיל מעקב מיקום ברקע.
- השתמש במחרוזות משאבים לתרגום ולתמיכה בעברית.
- ודא שכל המסכים עובדים ב־RTL.
- הפרד את מנוע המסלולים מממשק המשתמש.
- שמור על נתוני דוגמה מסומנים בבירור.
- לפני הוספת ספרייה, הסבר למה היא נדרשת ומה הרישיון שלה.
- בסיום כל שלב, סכם קבצים ששונו, בדיקות שבוצעו, בעיות שנותרו והשלב הבא.

## סדר מימוש מומלץ
1. שלד Android עם מסך חיפוש ומצב דוגמה.
2. מודלים למסלול ולמקטעים.
3. ממשק `TransitDataProvider` בלי לקבע ספק.
4. תוצאות מסלול לדוגמה עם פירוט מלא.
5. בחירת ספק נתונים וחיבור אמיתי.
6. בדיקות חישובי זמן ודירוג.
7. העדפות משתמש.
8. תיעוד נסיעה והגנת פרטיות.
